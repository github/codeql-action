- When the CodeQL Action autodetects languages and CodeQL finds no source code in the checkout for an autodetected language that it extracts without a build, the `analyze` step now skips that language with a warning instead of failing. The GitHub languages API describes the default branch and can be out of date, so it could report a language whose last file had been removed. If no autodetected language has source code, the `analyze` step still fails. [#4335](https://github.com/github/codeql-action/pull/4335)
